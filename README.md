# AI Base

Личный конспект по AI, Claude и подготовке к Claude Certified Architect (Foundations) —
с карточками, мок-экзаменом и практикой с AI. PWA: ставится на телефон, работает офлайн,
сборки нет.

## Запуск

```bash
npm run dev     # http://localhost:3000
```

Service worker и ES-модули требуют `http://` — открывать `index.html` через `file://` нельзя.

## Что внутри

| Экран | Маршрут | Что делает |
|---|---|---|
| Главная | `#/` | Разделы, колода, повторение, мок-экзамен |
| Раздел | `#/s/<id>` | Темы или модули раздела + прогон вопросов по всему разделу |
| Модуль | `#/m/<section>/<module>` | Темы модуля |
| Тема | `#/t/<id>` | Конспект: главное, термины, команды, самопроверка + панель AI |
| Карточки | `#/cards` | Колода: что отложено из тем |
| Повторение | `#/review` | Интервальное повторение (1, 3, 7, 16, 35 дней) |
| Мок-экзамен | `#/exam`, `#/exam/<домен>` | Вопросы по доменам CCAR-F, разбор ошибки с AI |
| Настройки | `#/settings` | Провайдер, ключ, модель, экспорт/импорт карточек |

## Контент

Весь учебный текст — в `data/content.js` (разделы → модули → темы) и `data/exam.js`
(домены и банк вопросов). Тема рисует только те блоки, которые в ней заполнены:
`points`, `terms`, `commands`, `code`, `qa`, `links`. Формат полей описан комментарием
в начале `data/content.js`.

## AI

Провайдер выбирается в настройках: Claude (Anthropic Messages API) или Gemini.
Ключ лежит в `localStorage` и уходит прямо из браузера в API провайдера — своего бэкенда
у приложения нет, поэтому вводить сюда стоит личный ключ, а не рабочий.

## Деплой

Vercel, без сборки: Framework Preset **Other**, пустые build command и output directory.
Заголовки кэша задаёт `vercel.json`.

**После добавления или переименования файла** допиши его в `SHELL` в `sw.js` и подними
`VERSION` — иначе установленное приложение продолжит отдавать старую версию.
