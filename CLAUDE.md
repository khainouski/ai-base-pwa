# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

AI Base — личное PWA для изучения и повторения AI: конспекты (основы агентов, Claude,
команды Claude Code, подготовка к CCAR-F), карточки с интервальным повторением,
мок-экзамен и практика с AI. Без сборки, без бандлера, без бэкенда, без тестов —
браузер грузит ES-модули как они лежат на диске.

## Commands

```bash
npm run dev      # статика на http://localhost:3000 (npx serve)
```

`file://` не годится: service worker и модули требуют `http://`.

Деплой — Vercel без сборки (Framework Preset **Other**, пустые build command и output
directory); `vercel.json` задаёт заголовки кэша.

## Critical: поднимать `VERSION` в `sw.js`

`sw.js` перечисляет оболочку руками (каждый файл `js/`, `data/`, `css/` и иконки).
После добавления, переименования или удаления файла допиши его в `SHELL` **и** подними
`VERSION` (`v1` → `v2`) — иначе установленные копии продолжат отдавать старый кэш.
Это самый частый способ сломать изменение в этом репозитории.

## Architecture

Хэш-роутер → вьюхи → общие помощники → хранилище и AI.

- **`js/router.js`** — точка входа. Разбирает `#/kind/a/b` (`s` раздел, `m` модуль,
  `t` тема, `cards`, `review`, `exam`, `settings`), чистит `#app`, зовёт одну
  `render*(root, ...)`. Здесь же глобальный поиск: индекс строится один раз из
  `data/content.js` и ищет по заголовкам, терминам, командам и вопросам.
- **`js/views/*.js`** — по экрану на файл, каждый экспортирует `async render*(root, ...)`.
  Вьюхи собирают HTML строками: фреймворка и виртуального DOM нет.
  `practice.js` — не маршрут, а панель AI (`mountPractice(slot, ctx)`), которую встраивают
  страницы темы, раздела и модуля.
- **`data/content.js`** — весь учебный текст: `SECTIONS` (раздел → модули → темы),
  `TOPICS` по идентификатору, плюс производный `TOPIC_INDEX` и хелперы. Формат полей темы
  описан комментарием в начале файла. Это конспект владельца — не переписывай формулировки
  под «как принято в учебниках».
- **`data/exam.js`** — `DOMAINS` (домены CCAR-F с весами) и `QUESTIONS` (банк вопросов).
  Правильный ответ хранится индексом: варианты перемешиваются при показе.
- **`js/storage.js`** — единственный слой хранения (`localStorage`, префикс `aibase:`).
  API асинхронный намеренно. Здесь же `PROVIDERS` (провайдеры, их модели и ссылки на ключи),
  `LEVELS` и `INTERVALS_DAYS` — расписание Лейтнера (1, 3, 7, 16, 35 дней; неверный ответ
  сбрасывает `step` и возвращает карточку через 10 минут).
- **`js/ai.js`** — все вызовы модели. Два адаптера (Anthropic Messages API и Gemini) за
  одним `ask(prompt, { temperature })`, оба отдают разобранный JSON. Ключ идёт заголовком;
  для Anthropic из браузера обязателен `anthropic-dangerous-direct-browser-access`.
  HTTP-статусы превращаются в русский `AiError` с `code`.
- **`js/prompts.js`** — все промпты. Каждый встраивает `topicBrief()` — выжимку из
  конспекта, чтобы модель спрашивала по записанному, а не по своим представлениям.
  Новый AI-режим добавляется сюда, а не внутрь вьюхи.
- **`js/cards.js`** — превращение конспекта в карточки. Идентификатор детерминирован
  (`topicId:term:3`), поэтому повторное добавление не плодит дубли и не сбрасывает расписание.
- **`js/ui.js`** — строковые помощники: `esc` (всегда экранировать текст модели), `el`,
  `mdLite`, `crumbs`, `rowList`, `topicBody`, `loading`, `errorBox`, `toast`, `plural`, `copyText`.
- **`js/pwa.js` / `js/install.js`** — регистрация SW, перезагрузка по `controllerchange`
  (подавляется, пока пользователь печатает), баннер установки для iOS.

## Conventions

- Интерфейс, ошибки и комментарии — по-русски; английскими остаются термины, код, флаги
  и имена файлов. Комментарии объясняют *почему*, а не пересказывают код.
- Никаких зависимостей, фреймворков и TypeScript. Обычные ES-модули с относительными
  путями и расширением `.js`.
- Всё, что пришло от модели, — недоверенный текст: только через `esc()` или `mdLite()`.
- Запись в `localStorage` может бросить (приватный режим Safari); `storage.js` это гасит,
  приложение обязано работать и без хранилища.
- Каждый экран ниже корня рисует `crumbs()`: с домашнего экрана это единственный выход.
  `js/router.js` нумерует записи истории в `history.state.aibase`, чтобы ссылка делала
  настоящий `history.back()`, а в позиции 0 уходила по своему `href`.
